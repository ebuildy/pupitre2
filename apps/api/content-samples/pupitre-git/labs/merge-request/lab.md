# Lab : votre première merge request

Dans votre projet GitLab `e-learning/<votre identifiant>` :

1. sur la branche par défaut, ajoutez un fichier `lab.py` qui définit une fonction `main()` ;
2. créez une branche et ouvrez une merge request vers la branche par défaut ;
3. attendez que le pipeline de la merge request réussisse.

Revenez ici et cliquez sur « Vérifier cette étape ».
